# Checklist iPad Air — Safari iOS 12.5.8

Probar con la aplicación desplegada y también después de una recarga completa.

- [ ] Abre el shell sin pantalla blanca y muestra el catálogo real o datos guardados.
- [ ] Navega Hoy, Explorar, Despensa, Favoritos, Semana, Historial y Administrar.
- [ ] Cambia las cinco franjas; ninguna queda bloqueada por la hora.
- [ ] Busca por título, ingrediente y alias.
- [ ] Usa paginación y confirma que los controles tienen targets cómodos.
- [ ] Abre detalle y Modo Cocina; verifica cantidades, medidas y contraste a distancia.
- [ ] Marca favorito, ingrediente de despensa, historial y semana con conexión.
- [ ] Gira a portrait y landscape; confirma que no hay overflow horizontal accidental.
- [ ] Recarga con conexión y confirma que primero aparece el catálogo cacheado y después se actualiza.
- [ ] Carga una pantalla sin conexión; debe mostrar “Sin conexión · Mostrando datos guardados”.
- [ ] Sin conexión, confirma que las escrituras explican que se necesita conexión y no quedan simuladas.
- [ ] Prueba teclado externo/focus visible y cerrar avisos o modales.
- [ ] Activa “Reducir movimiento” cuando esté disponible y revisa que no haya animaciones molestas.
