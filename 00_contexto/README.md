# Dieta Personal — Contexto Maestro

## Objetivo

Construir una aplicación web personal para gestionar y consultar un plan de alimentación real desde PC, móvil y, de forma prioritaria, un iPad antiguo con iOS 12.5.8.

La aplicación debe facilitar:

- Ver qué comer según el momento del día.
- Navegar libremente entre desayuno, medio día, comida, media tarde y cena.
- Buscar por platillo o ingrediente.
- Saber qué opciones se pueden preparar con lo que hay en casa.
- Evitar repetir comidas demasiado seguido.
- Marcar favoritos.
- Desactivar opciones que no gusten.
- Editar ingredientes, cantidades y notas.
- Generar ideas con base en la despensa.
- Generar una semana de comidas.
- Generar lista del súper.
- Funcionar rápido incluso en Safari antiguo.

## Principio de producto

> La hora sugiere, nunca bloquea.

Si el usuario abre la app de noche, Cena aparece destacada, pero siempre puede entrar a cualquier otro apartado.

## Fuente principal

Usar `DietaCompleta.docx` como fuente principal para importar el contenido.

Los documentos separados pueden usarse para validación.

1. Compatibilidad con iPad iOS 12.5.8.
2. Velocidad.
3. Fluidez.
4. Claridad visual.
5. Experiencia táctil.
6. Frontend atractivo.
7. Búsqueda.

El frontend es una prioridad crítica del proyecto.
