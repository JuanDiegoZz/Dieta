# Calidad de datos

## Problemas esperados

- yogur/yogurt,
- tomate/jitomate,
- unidades distintas,
- marcas comerciales,
- nombres repetidos con ingredientes distintos,
- componentes sin etiqueta explícita,
- notas,
- bebidas dentro de una comida.

## Duplicados

No considerar dos opciones duplicadas solo porque tienen el mismo nombre.

Comparar:

- franja,
- componentes,
- ingredientes,
- cantidades.

## Versiones

Si tienen mismo nombre pero composición diferente:

mantener ambas.

## Marcas

Conservar marca en el texto original.

También permitir búsqueda por ingrediente genérico.
