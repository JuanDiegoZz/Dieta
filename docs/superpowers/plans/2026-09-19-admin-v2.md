# Administrar v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Completar Administrar v2 con edición transaccional, ocultos/restauración, ingredientes globales, búsqueda, backup y validación segura de importación.

**Architecture:** Reutilizar bootstrap, cache, preferencias y handlers existentes. Añadir una RPC PostgreSQL aditiva para operaciones de árbol y RPCs administrativas seguras; el cliente seguirá llamando al BFF Node y solo actualizará estado/cache después de respuestas confirmadas.

**Tech Stack:** Vite, React 19, TypeScript, Vercel Node Functions, Supabase REST/PostgreSQL, IndexedDB/session cache, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-19-admin-v2-design.md`

## Global Constraints

- `meal_preferences.hidden` y `meal_options.active` son semánticas independientes.
- Las Vercel Functions usan `(req, res)` y `api/_lib/http.ts`; no usar `new Response()` en handlers.
- No cargar Supabase SDK ni secretos en el cliente.
- Preservar cantidades, unidades, medidas caseras, `original_text`, aliases e IDs existentes al editar.
- Mutaciones offline se rechazan; cache y fallback son solo lectura.
- No modificar migraciones existentes, catálogo importado ni datos reales para probar.
- No implementar importación que escriba en DB.
- No agregar dependencias nuevas.
