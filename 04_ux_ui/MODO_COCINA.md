# Modo Cocina

## Objetivo

Pantalla diseñada específicamente para usar desde la cocina.

## Requisitos

- letras grandes,
- alto contraste,
- botones grandes,
- poco contenido secundario,
- no depender de hover.

## Ejemplo

```text
Quesadillas de champiñones

Tortilla de maíz
90 g
3 piezas

Champiñones
183 g
1 ½ tazas

Queso panela
80 g
2 rebanadas

[ Terminé ]
```

## Funciones

- volver,
- favorito,
- notas,
- marcar terminado.

No incluir cronómetro o pasos si no existen en la fuente.
