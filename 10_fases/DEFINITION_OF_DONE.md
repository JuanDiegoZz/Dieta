# Definition of Done

Una función no está terminada hasta que:

- funciona en desktop,
- funciona en móvil,
- funciona en iPad target,
- tiene loading state si aplica,
- tiene error state si aplica,
- funciona con teclado cuando corresponda,
- es usable táctilmente,
- no introduce regresiones,
- respeta diseño,
- está documentada.

## La aplicación final debe

- cargar rápido,
- sentirse fluida,
- tener navegación obvia,
- mostrar todas las franjas siempre,
- buscar rápido,
- funcionar con cache,
- permitir editar todo el plan,
- registrar historial,
- recomendar sin inventar información.
