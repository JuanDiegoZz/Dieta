# Prompt para trabajo de UI

Revisa:

- `04_ux_ui/`
- `05_compatibilidad/`

Implementa la UI priorizando:

- fluidez,
- claridad,
- responsive,
- uso táctil,
- Safari/iOS antiguo.

No quiero una interfaz de dashboard empresarial.

Quiero una experiencia similar a una aplicación de consumo moderna:

- cards limpias,
- navegación clara,
- iconos consistentes,
- microinteracciones,
- espacios amplios,
- estados vacíos bien diseñados,
- skeletons,
- transiciones rápidas.

Las animaciones no pueden comprometer rendimiento.

Implementa progressive enhancement:
- modern browsers: experiencia completa,
- legacy iPad: mismas funciones, efectos reducidos.
