# Prompt inicial para Codex

Vas a construir una aplicación web personal de alimentación.

Antes de escribir código:

1. Lee TODOS los archivos `.md` de este repositorio.
2. Resume en un archivo `IMPLEMENTATION_PLAN.md` la arquitectura que entendiste.
3. No cambies las decisiones del producto sin documentarlo.
4. Prioriza compatibilidad con iOS 12.5.8, rendimiento y UX.
5. No instales librerías innecesarias.
6. Usa TypeScript.
7. El frontend es una prioridad crítica.

Comienza por:

- estructura del proyecto,
- design system,
- build legacy,
- esquema de datos,
- importer skeleton,
- pantalla Hoy.

No intentes implementar todo en una sola entrega.

Trabaja por fases y valida cada fase antes de continuar.
