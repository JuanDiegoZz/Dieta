# Plan semanal

## Objetivo

Generar automáticamente una propuesta semanal usando únicamente opciones existentes.

## Reglas

- respetar franja,
- evitar repeticiones,
- priorizar favoritos moderadamente,
- aprovechar despensa,
- variar proteínas/ingredientes principales cuando sea posible.

## Interfaz

Vista semanal.

Cada celda permite:

- cambiar opción,
- limpiar,
- bloquear.

## Regenerar

Si una opción está bloqueada, `Regenerar semana` no debe modificarla.

## Resultado

El plan semanal puede producir una lista del súper.
