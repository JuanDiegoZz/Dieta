# Historial y no repetir

## Acción principal

Botón:

`Preparé esto`

Al pulsarlo:

- crear registro meal_history,
- actualizar UI inmediatamente,
- reordenar recomendaciones.

## No repetir

Configuración:

```text
Evitar repetir durante: 7 días
```

No debe bloquear necesariamente.

Debe reducir prioridad.

## Historial

Mostrar:

- fecha,
- hora,
- nombre,
- franja,
- rating opcional.

## Acciones

- volver a preparar,
- favorito,
- editar registro,
- eliminar registro.
