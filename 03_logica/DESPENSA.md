# Mi despensa

## V1

La despensa debe ser sencilla.

Estado principal:

- Tengo
- No tengo

Opcional:

- Usar pronto

No implementar inicialmente cantidades exactas de inventario.

## Interfaz

Buscador de ingredientes.

Cada resultado:

- icono,
- nombre,
- toggle Tengo,
- botón Usar pronto.

## Uso

La despensa alimenta:

- recomendaciones,
- filtro `Puedo hacerlo`,
- lista de faltantes.

## Detalle de comida

Mostrar:

```text
Tienes:
✓ tortilla
✓ queso

Te falta:
✗ champiñones
```
